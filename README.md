## 如何使用

### 介面改善（2026-10-09）

- 操作介面分為「基本資料 → 匯入明細帳 → 核對與產製」三步，保留單一 HTML 離線使用方式。
- 頁首直接顯示工具名稱，移除大型「餐」字方塊、文件圖示及「校務會計／午餐結算」文字；三步流程移除上下橫線與中間分隔線。
- 頁面最底下加入淡色 `by ccw` 浮水印。
- PDF 選取後逐份列出檔名、大小與總量；月份設定維持選填並自動儲存。
- 改善文字對比、欄位及按鈕尺寸、鍵盤焦點與小螢幕排版。分類核對出現時會將焦點移至核對區。
- 未選 PDF 時會顯示提示並移至選檔按鈕；拖入非 PDF 會提示重新選檔。
- 使用三份實際 PDF 樣本完成產製驗證，並檢查 375、768、1024、1440 像素版面、月份切換與減少動態效果設定。
- 開發驗證可使用 `node verify_ui.cjs`；腳本使用本機 Edge 與 Codex 隨附 Playwright，會產生 `介面預覽.png` 與 `UI驗證產出.xlsx`。此腳本為開發環境用途，日常操作不需要執行。

1. 雙擊開啟 `午餐明細帳轉換工具.html`，不需安裝軟體或連線。
2. 輸入民國學年度；校名可由 PDF 標題自動帶入，也可手動輸入或選常用校名。
3. 選取一份或多份會計明細帳 PDF。需要時可另外選擇 `.xlsx` 結算表範本；未選時使用內建範本。
4. 展開「月份與收費設定」，用月份下拉選單編輯該月資料。資料會分月自動記憶在目前瀏覽器。
5. 按「確認並產製 Excel」。若出現分類待核對清單，逐筆選擇支出科目，再按「確認分類並產製 Excel」。分類清單未選完前不會產生 Excel。
6. 產製完成後按「下載 Excel 檔」。

## 結算表功能

### C4 說明

- 依輸入的人數、收費費率、免減收與未繳資料組成說明文字。
- 每人收費預設 800 元，可逐月調整；人數欄位由使用者依月份登打。
- 教職員與工友人數合計會帶入 B16 教職員收費資料的人數。
- C4「應收午餐費」合計優先使用 B16 收費欄位的學期繳金額加月繳金額；未輸入 B16 收費金額時，改用 PDF 的本月午餐費收入。
- 會將依人數、費率、免減收與未繳金額推算的數字和 PDF 午餐費收入比對；有差異時提示核對，不阻止產檔。
- 該月未填 C4 資料時，保留範本內容，方便在 Excel 補登。

### B16 備註

- 補助計畫可選明細帳計畫，輸入核定起迄月份及金額；產製月份適用時自動帶入備註。
- 核定期間相同的計畫共用一次期間文字，例如「115年9-12月核定免費學生午餐補助款1,542,400元、精進學校菜單方案補助款934,500元」。
- 學期繳、月繳人數與金額可逐月設定。金額欄位即時加總，合計同步帶入 C4；手動改寫備註文字不會改變欄位加總。
- 備註草稿可以逐月修改並由瀏覽器記憶。C4 與 B16 寫入合併儲存格左上角，保留範本合併範圍與主要版面格式。
- B16 第一、二項分行；第三項起以空格接續，並依儲存格寬度折行、調整列高。
- 本月午餐費、其他收入及午餐退費，依明細帳收入資料產生備註，項次會自動重新編號。
- **2026-10-10 更新：其他收入摘要與顯示選項。** 展開「月份與收費設定」，在「B16 收入備註顯示選項（所有月份）」勾選或取消「顯示其他收入」及「顯示午餐退費」。兩項預設勾選，適用所有月份；金額為 0 或空白時不顯示。
- 其他收入取當月最早一筆有金額的其他收入明細摘要，去除開頭的「收」及結尾標點後，加上「等」。例如當月其他收入合計 2,000 元，第一筆摘要為「收楊校長捐助午餐專戶」，顯示「四、其他收入2,000元係楊校長捐助午餐專戶等。」；實際項次依前面備註數量調整。
- 午餐退費以正數金額顯示，例如「五、午餐退費500元。」。取消勾選只控制 B16 備註顯示，明細帳金額仍照常列入。
- 兩個顯示選項會自動記憶在目前瀏覽器，並隨「匯出／匯入基本資料與收費設定」備份及還原。

## 明細帳與 Excel 格式

- 依 PDF 檔名或會計系統子目辨識計畫；支出摘要已有 `-科目-` 時優先依該科目分類。
- 關鍵字推定或無法判斷的支出會先列入「分類待核對」，由使用者選擇科目後才產製。
- 匯出前保留逐筆明細；摘要會換行，列高依內容調整。
- PDF 摘要若因版面換行成多列，會將同頁、緊接在交易列下方的續行文字併回該筆摘要。
- 明細帳憑單字別依會計系統代碼轉示：I 顯示為「支」、H 顯示為「收」；憑單號碼保留。
- 結算表 C4、C12 字體設為 11 號；明細與結算儲存格及文字內部分段字型統一為標楷體，包含 D9「燃料費(水電)」及分類帳文字。
- 產製後仍請核對月底餘額、收入金額與分類結果。
- 下載檔名會自動加上產製年月，例如「午餐結算明細表_115學年度_115年10月產製.xlsx」。

## 設定記憶與備份

- 展開「本機資料管理」可查看已填月份、補助計畫、常用校名數量與設定儲存用量。
- 可先匯出備份，再選擇清除目前月份、所有月份、補助核定計畫、常用校名或全部本機記憶；清除前會顯示確認提示。
- 清除月份資料時保留補助計畫，因此適用月份的自動備註仍會重新產生；清除補助計畫時保留手動備註。
- 清除後舊的 Excel 下載連結會收起，請重新產製。清除只處理本工具的設定，不會刪除電腦上的 PDF、Excel 或已下載的備份。後續輸入新資料時會再次自動記憶。

- 校名、月份資料、補助計畫及備註草稿會存在目前瀏覽器的本機儲存區。
- 可用「匯出基本資料與收費設定」下載 JSON 備份，再以「匯入基本資料與收費設定」還原。
- 換瀏覽器或清除瀏覽資料前，請先匯出備份；本機記憶不會自動同步到其他電腦。
